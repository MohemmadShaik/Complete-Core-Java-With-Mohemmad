Practice 4 : Linear Search 
find the index of element in a given array

                key=10
_____________________ 
|2|4|6|8|10|12|14|16| 

Let's say we want to find key value 10 from the list of
elements of an array, then will check each element with it's
index value. 

As we all know the array index value starts from 0, 
So will start checking from index 0 such that any element 
is matching with our key value 10.

If match found will return the index value where the 
element gets matched. 

Here we can see the index value 4 has the key value 10. 
So it will return the index value 4 as the key value 10 
gets matched.

//Practice 4.1 : Linear Search for given array of numbers.
//LinearSearch : Finding the index value of an array which contains numbers.
public class Practice8_4_1_Arrays_LinearSearch {
    public static int linearSearch(int number[], int key){
        for(int i=0; i<number.length;i++){
            if (number[i]==key){
                return i;
            }   
        }
        return -1;
        
    }
    public static void main(String[] args) {
        int number[] = {2,6,5,15,10,3,16};
        int key =16;
       int index = linearSearch(number, key);
       if(index == -1){
        System.out.println("\nKey not found.");
       }else{
        System.out.println("\nKey found at index :"+index);
       }
       System.out.println();
    }
}

Practice 5 : Find Largest in Array int numbers[] ={2,4,7,3,5,1}
time complexity : O(n) (We call it as Big of n) 
because we did n elements operations which means we did operations for all the elements in the given array.
Key note :
   -infinity : Integer.MIN_VALUE 
   +infinity : Integer.MAX_VALUE

   Step 1  : initialize a variable with Integer.MIN_VALUE
               int Largest = Integer.MIN_VALUE; //-infinity
    
    Step 2 : Now compare each element of the given array with this Largest variable using for loop and if condition.
              if(Largest<numbers[i])
    
    Step 3 : At first only the condition gets failed because currently Largest variable is storing -ve value in it.
    Step 4 : Now assign the Largest variable to numbers[i]
              Largest = number[i];
    Step 5 : Similarly it will check all the array elements with the Largest number.
             if Largest variable is found lesser compare to numbers[i], the Largest 
             variable gets updated.
//Practice 5 : Find the largest and smallest number in the given array {2,4,7,3,5,1}
public class Practice8_5_1_Arrays_Largest_Smallest_Num {

    public static int getLargestNum(int numbers[]){
        int largest = Integer.MIN_VALUE; //-infinity
        int smallest = Integer.MAX_VALUE; //+infinity
        for(int i=0; i<numbers.length; i++){
            if(largest<numbers[i]){
                largest = numbers[i];
            }
            if(smallest>numbers[i]){
                smallest=numbers[i];
            }
        }
        System.out.println("\nSmallest number is : "+smallest+"\n");
        return largest; 
    }
    public static void main(String[] args) {
        int numbers[] = {2,4,7,3,5,1};
       System.out.println("\nLargest number is : "+getLargestNum(numbers)+"\n");
    }
}


//Different approach to print larger and smaller value for a given array.
public class Practice8_5_2_Arrays_Largest_Smallest_Num {
    public static int printBigSmallNum(int myNum[], boolean findBig) {
        if (findBig) {
            // finding big number
            int big = Integer.MIN_VALUE;
            for (int i = 0; i < myNum.length; i++) {
                if (big < myNum[i]) {
                    big = myNum[i];
                }
            }
            return big;
        } else {
            // finding small number
            int small = Integer.MAX_VALUE;
            for (int i = 0; i < myNum.length; i++) {
                if (small > myNum[i]) {
                    small = myNum[i];
                }
            }
            return small;
        }
    }

    public static void main(String[] args) {
        int myNum[] = { 3, 5, 2, 0, 12, 11 };

        int small = printBigSmallNum(myNum, false);
        System.out.println("\nSmall number is :" + small);
        int big = printBigSmallNum(myNum, true);
        System.out.println("\nBig number is :" + big + "\n");

    }
}

//Practice 6 : Find the index value of the element 12 in an arr[] ={2,4,6,8,10,12,14} using binary search.

Note : If we are using binary search then we need the following:
        1.start value --> 0 since array index starts from 0
        2. End value --> length of an array 
        3. while condition --> while(start<=end)
        4. mid value --> int mid = (start+end)/2;
        5. mid = key --> key found
        6. mid > key --> end = mid - 1
        7. mid < key --> start = mid + 1
public class Practice8_6_1_BinarySearch {

    public static int binarySearch(int numbers[], int key) {
        int start = 0, end = numbers.length - 1;

        while (start <= end) {
            int mid = (start + end) / 2;

            // comparisons
            if (numbers[mid] == key) {
                return mid;
            }
            if (numbers[mid] < key) { // right
                start = mid + 1;
            } else { // left
                end = mid - 1;
            }
        }
        return -1;
    }

    public static void main(String[] args) {
        int numbers[] = { 2, 4, 6, 8, 10, 12, 14 };
        int key = 18;

        System.out.println("index for key is  : " + binarySearch(numbers, key));

    }
}

//Practice 7 : Reverse the elements in an array arr[] ={20,30,49,67,78,88,90} using a function.
Note : If the given array is in ascending order then make it descending order or vice versa.
public class Practice8_6_2_ReverseArray {
    public static void reverse(int arr[]) {
        int start = 0, end = arr.length - 1;
        while (start < end) {
            int temp = arr[start];
            arr[start] = arr[end];
            arr[end] = temp;
            start++;
            end--;
        }
    }

    public static void main(String[] args) {
        int arr[] = { 20, 30, 49, 67, 78, 88, 90 };
        reverse(arr);
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i] + " ");
        }
    }
}

/Practice 8 : Write a function to print all pairs of the given arr[] = {2,4,6,8,10} and also print total number of pairs of the given array.
output : (2,4)(2,6)(2,8)(2,10)
         (4,6)(4,8)(4,10)
         (6,8)(6,10)
         (8,10)
Note : Here we have to use the nested loop to print the pairs of an array.

Total pair (tp) = n(n-1)/2  ------> (n-1) + (n-2) + (n-3) +..3 + 2 + 1 
                  
Total Number of Pairs Calculation
----------------------------------
If there are n elements, the number of pairs each element
makes follows this pattern:

-->1st element pairs with n−1 elements
-->2nd element pairs with n−2 elements
-->3rd element pairs with n−3 elements
-->.....
-->(n-1)th element pairs with 1 element
-->nth element doesn’t pair with anyone

Thus, the total number of pairs is:
(n−1)+(n−2)+(n−3)+...+2+1

This is the sum of the first (n-1) numbers, which follows
the formula: n(n-1)/2

Time complexity : o(n^2)

class Practice8_7_ArrayPairs{
    public static void arrayPairs(int arr[]){
		for(int i=0; i<arr.length; i++){
			int current = arr[i]; //2,4,6,8,10
            System.out.print("\n");
			for(int j=i+1; j<arr.length; j++){
				System.out.print("("+current+","+arr[j]+")");
			}
			System.out.print("\n");
		}   
    }
    public static void main(String[] args) {
        int arr[] = {2,4,6,8,10};
        arrayPairs(arr);
    }
}
